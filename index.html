Flutter

¿Qué es Flutter?

Flutter es un conjunto de herramientas (SDK) y framework de código abierto creado por Google. Permite desarrollar aplicaciones visualmente atractivas y de alto rendimiento para múltiples plataformas (iOS, Android, Web, Windows, macOS y Linux) utilizando un único código base y el lenguaje de programación Dart

SDK de Flutter y Comandos eficientes

El SDK de Flutter es el kit de herramientas de interfaz de usuario de Google que permite compilar aplicaciones nativas para móviles, web y escritorio desde una única base de código usando Dart. El desarrollo es altamente eficiente gracias a comandos integrados en la terminal.

Comandos utiles:

flutter doctor: Esencial. Verifica tu entorno de desarrollo, detectando dependencias faltantes (como SDKs de Android/iOS) o problemas de configuración.

flutter channel: Cambia entre canales de Flutter (ej. stable, beta).

flutter upgrade: Actualiza el SDK de Flutter y sus dependencias a la última versión disponible.

flutter create : Crea la estructura básica de un nuevo proyecto.

Dart

Dart es un lenguaje de programación de código abierto desarrollado por Google. Su popularidad ha crecido enormemente en los últimos años por ser el lenguaje oficial utilizado para crear aplicaciones móviles, web y de escritorio con el framework Flutter.

Desarrollo Mobile

El desarrollo mobile (o desarrollo de aplicaciones móviles) es el proceso de crear software diseñado específicamente para ejecutarse en dispositivos portátiles como teléfonos inteligentes, tablets o relojes inteligentes.

Que es un Widget

En Flutter, todo es un widget. Es la unidad básica y fundamental para construir la interfaz de usuario. Desde un simple texto, un botón o una imagen, hasta elementos invisibles como el alineamiento, el espaciado o la estructura de la pantalla: todo se crea combinando widgets como si fueran piezas de Lego.

StatelessWidget

Es un widget estático e inmutable. Su contenido se dibuja una sola vez en la pantalla y no cambia a lo largo del tiempo. Se utiliza cuando la información que muestra es fija y no depende de la interacción del usuario ni de datos que cambien en tiempo real.

StatefulWidget

Es un widget dinámico e interactivo. Tiene la capacidad de almacenar un "estado" interno (datos en memoria) y, cuando ese estado cambia (mediante la función setState), el widget se redibuja automáticamente para reflejar la nueva información en la pantalla.
